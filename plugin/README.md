# phyein-topopt plugin

Structural topology optimisation with the `phyein-topopt` toolchain.

- `topology-optimisation`: the method, derived step by step; loads from physics and standards;
  decision guide; pipeline; acceptance checks; failure modes; honesty labelling.
- `topopt-toolchain`: the pinned image, GitHub runners, Kaggle, timings, storing and publishing.
- `topopt-run`: launch a run (time estimate first, then the user's explicit yes).
- `topopt-results`: fetch a run, check it, present it.

Needs: the public repository `phyein-topopt` on the user's GitHub account, attached to the session.
No credentials are stored in this plugin.
